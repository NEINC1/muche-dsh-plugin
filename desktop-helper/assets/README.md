# 桌面立绘来源

`dsh-pet-idle.webm` 是 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 的
`dsh-pet/assets/webm/待机呼吸休闲.webm` 原始透明动画。源仓库版本：
`48426c387d6222293bbc25e0b264231875a5bac1`。`dsh-pet-idle.json` 记录播放裁剪区域；
该区域覆盖原片全部 241 帧的非透明人物，动画文件未修改。
